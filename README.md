## Run Instructions 

Ruby is **installed by default on all Mac OS configurations** since Mac OS 10.2 Jaguar. My program requires Ruby 2.6 or later, which is installed on all new Mac OS versions since Catalina. You can access it by typing

```
ruby --version
irb
```

IRB being the interactive shell for Ruby. To run a Ruby program (mine) use

```
ruby main.rb
```
and the program will execute
